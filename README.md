# Tic-tac-toe (React + Vite)

## 🚀 One-click launch

| | Link |
|---|---|
| **Play online** | `https://YOUR-USERNAME.github.io/tic-tac-toe-react/` |
| **Open in StackBlitz (runs in browser)** | `https://stackblitz.com/github/YOUR-USERNAME/tic-tac-toe-react` |

> Replace `YOUR-USERNAME` with your GitHub username.

## Run locally

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build in dist/
```

Play with a friend, or against the computer (Easy = random moves, Hard = unbeatable minimax).

`tic-tac-toe-standalone.html` is a single-file version that works by double-clicking it.
